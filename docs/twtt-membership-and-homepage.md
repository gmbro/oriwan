# TWTT 공개 홈페이지 기획서

2026-09-13 개정 · 홈페이지 신규 화면과 구독 상품은 기획 단계다. 기존 4기 대시보드와 인증 서비스는 운영 중이며, 아래 주소는 신규 화면의 제안 경로다. 이 문서를 홈페이지·구독·공동 목표의 최신 기준으로 사용한다.

## 1. 서비스 방향

**TWTT를 방문하면 지금 참여할 도전과 모임을 발견하고, 지난 활동을 살펴본 뒤 직접 참여할 수 있도록 한다.**

TWTT는 전체 브랜드, 스내사는 TWTT 안의 기수제 챌린지, 커뮤니티 모임은 러닝·교정운동 등 상시 활동으로 구성한다. 4기가 끝나도 홈페이지는 다음 기수와 다른 커뮤니티를 계속 소개한다.

기존 도메인의 `/`를 공개 홈페이지로 사용하고 `/4th/dashboard`는 인증과 개인 활동을 위한 기존 서비스로 유지하는 것을 권장한다. 별도 도메인 구매는 필수가 아니다. 처음 방문한 사람은 로그인 없이 소개·일정·후기를 읽고, 신청이나 개인 기록 이용 시 카카오 로그인한다.

## 2. 메뉴와 페이지 구조

상단 메뉴는 **스내사 · 모임 · 이야기 · 멤버십**, 별도 버튼은 **내 활동**으로 간결하게 구성한다. 광고 안내는 홈의 파트너 영역과 하단 메뉴에서 연결한다. 모바일에서도 동일한 순서를 유지한다.

| 페이지 / 제안 주소 | 방문자가 확인할 내용 | 주요 행동 |
| --- | --- | --- |
| 홈 `/` | TWTT 소개, 현재 도전, 다가오는 모임, 지난 활동, 파트너 | 진행 중인 도전 보기 |
| 스내사 `/snasa` | 스내사 소개, 현재 4기, 기수별 기록 | 4기 자세히 보기 |
| 4기 소개 `/snasa/4` | 기간·참가 기준·인증 방식·공동 목표·동의한 도전자 | 참가 신청 / 참여자는 인증하기 |
| 지난 기수 `/snasa/1`~`/snasa/3` | 기수 소개, 검증된 성과, 활동 사진, 회고 | 다음 도전 보기 |
| 모임 `/meetups` | 모집 중·진행 예정·종료 모임, 종류·지역 필터 | 모임 상세 보기 |
| 모임 상세 `/meetups/[slug]` | 주최자, 일정, 장소, 난이도, 정원, 비용, 취소 안내 | 신청하기 |
| 이야기 `/stories` | 참여 후기, 주간 소식, 인터뷰, 모임 회고 | 관련 도전 / 모임 보기 |
| 멤버십 `/membership` | 무료 이용과 대행 혜택 비교, 이용 기간, 가격·신청 안내 | 월 이용권 신청 |
| 파트너 `/partners` | 광고 위치, 기간, 월 요금, 소재·문의 안내 | 광고 문의 |

자료가 없는 기수에는 임의 성과나 가짜 후기를 만들지 않는다. 1·2기는 운영자가 자료를 확인한 후 발행하고, 3기는 기존 읽기 전용 자료의 공개 가능 범위를 검토해 재사용한다. 새 주소를 확정할 때 기존 공개 주소와 중복되지 않도록 이전·대표 주소 정책도 정한다.

첫 화면에는 소개와 행동 버튼 하나를 중심으로 둔다. 카드의 제목·보조 설명·버튼 위계를 통일하고 충분한 여백을 준다. 모션은 보조 연출로 사용하며 핵심 설명을 이미지나 애니메이션 안에만 넣지 않는다. 자동 재생 배너에는 정지 버튼과 동작 줄이기 설정을 적용한다.

## 4. 스내사 4기와 공동 목표

4기 소개는 **취지 → 일정과 참여 방법 → 인증 규칙 → 공동 목표 → 공개 도전자 → FAQ → 참가 신청** 순서다. 시작 전에는 준비 기간임을 표시하고 공식 기록과 혼합하지 않는다. 신규 참가 모집 여부·정원·참가비는 운영자가 설정하며 확인되지 않은 모집 상태를 임의로 표시하지 않는다.

공동 목표는 시즌 전체 누적 승인 러닝 거리 기준으로 **1,000 → 2,027 → 5,000 → 10,000km**다. 매 단계마다 거리를 다시 0으로 만들지 않는다.

현재 대시보드 표현은 ‘N명 중 N명이 인증했어요’ 아래 작은 영역에 영어 제목과 현재 목표를 세로로 보여준다. 예: `FIRST COMMUNITY GOAL` / `1,000km` / `달성하면 다음 목표가 열립니다`. 번호와 잠긴 2·3·4단계의 `???` 목록은 표시하지 않는다. 달성 시 체크 피드백을 주고 다음 목표를 공개한다. 마지막 목표 달성 후에는 체크와 전체 목표 달성 문구를 유지한다. 공개 홈페이지도 동일한 현재 목표를 사용한다.

준비 기간·검수 대기·반려·회복 인증 환산 거리는 공식 공동 거리에 포함하지 않는다. 중복 제거와 승인 취소에 따른 재집계는 서버 기준을 따르고, 반올림 전 실제 거리로 달성 여부를 판단한다.

인증 안내는 **“오전 8시 이전에 운동을 시작했다는 시각이 보이도록 업로드해주세요”**를 사용한다. 업로드 시각이 늦어도 운동 날짜와 시작 시각의 증거를 확인한다. OCR은 입력 보조이며 운영자가 최종 승인한다. 제출 완료와 공식 승인 대기는 구분해 안내한다.

도전자는 검색 공개에 별도 동의한 닉네임·소개·대표 사진만 우선 노출한다. 인증 원본, 상세 이동 경로, 카카오 식별자, 연락처는 공개 페이지에 넣지 않는다. 참여 동의와 검색 공개 동의를 분리하고 공개 철회 기능을 제공한다.

## 5. 커뮤니티 모임

초기에는 운영자가 러닝·교정운동·번개 모임과 협력 커뮤니티 모임을 등록한다. 일반 회원의 모임 개설은 운영·신고 체계가 마련된 다음 단계로 둔다.

신청 흐름은 **공개 상세 확인 → 카카오 로그인 → 신청 정보 확인 → 신청 완료 → 내 모임에서 상태 확인**이다. 정원 초과는 대기 신청으로 처리하고 중복 신청을 막는다. 정확한 집결 위치나 주최자 개인 연락처는 필요한 경우 참가 확정자에게만 제공한다.

운영자는 초안·모집 중·마감·취소·종료 상태, 정원, 신청자, 대기자, 출석을 관리한다. 일정 변경·취소 시 신청자에게 알리고 취소 사유를 화면에 남긴다. 실제 유료 모임을 도입할 때 결제와 취소 기준을 별도로 확정한다.

## 6. 멤버십과 광고 상품

아래 세 가지 혜택은 사용자 요청사항이다. 제공 횟수의 기간 기준과 운영 방식은 제안이며, 가격과 제공 가능 인원을 확정하기 전 판매하지 않는다.

| 구분 | 무료 회원 | 멤버십 제안 |
| --- | --- | --- |
| 인증 제출 | 본인이 직접 업로드 | 운영자 업로드 대행, 기본 하루 1건·누락일 소급 요청 가능 |
| 공식 인증 | 동일한 증거 기준으로 운영자 승인 | 동일한 증거 기준으로 운영자 승인 |
| 광고 | 별도 월 10,000원 상품 | 구독 기간마다 소재 1건, 로테이션 내 연속 7일 노출 무료 |
| 교정운동 | 별도 신청 | 구독 기간마다 1회 무료 예약권 |

구독은 대행과 부가 서비스를 제공하는 상품이다. 결제 여부로 승인 기준을 바꾸지 않는다. 만료 후에도 직접 업로드와 기존 기록 이용을 유지한다.

초기 결제는 **계좌이체로 구매하는 1개월 이용권, 수동 연장**을 권장한다. 신청번호 발급 → 입금 → 운영자 실제 입금 확인 → 시작·종료일 확정 → 내 멤버십에서 혜택 잔여 횟수 확인 순서다. 사용자 ‘입금 완료’ 버튼만으로 활성화하지 않는다. 자동 갱신은 운영량이 안정된 뒤 검토한다.

멤버십 가격은 미정이다. 업로드 대행 시간, 교정운동 담당자 원가와 월 예약 가능 횟수, 광고 운영비를 계산해 정한다. 교정운동은 우선 20~30분 온라인 자세 피드백을 제안하되 담당자·범위·시간 확정이 필요하다. 미사용 혜택 이월, 노쇼, 환불, 운영자 사유 취소 규칙도 판매 전에 확정한다.

광고는 월 10,000원과 멤버십 포함 7일 노출을 별도 상품으로 관리한다. 권장 초기 범위는 기존 대시보드 로테이션이며, 홈페이지 파트너 영역은 추가 노출 위치로 명시해 운영한다. 독점 노출이나 클릭 수를 보장하지 않는다. 첫 운영안은 동시 소재 최대 5개로 제한하고 예약 가능한 시작일을 안내한다. 홈페이지 포함 여부·재고는 판매 전 확정한다.

광고 신청 → 소재 검수 → 입금 또는 광고권 확인 → 노출 기간·위치 확정 → 게시 → 만료 자동 종료 순서다. 문의 문구는 **“광고 문의는 개인 연락부탁드립니다.”**를 사용하되 실제 운영자 문의 채널은 설정값으로 연결한다. 광고 표기와 유료 링크의 `rel="sponsored noopener"`를 적용한다.

## 8. Google 검색 노출

홈페이지는 검색 가능한 공개 설명과 활동 기록을 쌓는 입구다. 제작만으로 색인이나 상위 노출이 보장되지는 않는다. 방문자가 실제로 궁금해하는 참여 시간·지역·비용·초보자 참여 여부를 고유한 본문으로 설명한다. [Google SEO 기본 가이드](https://developers.google.com/search/docs/fundamentals/seo-starter-guide).

초기 검색 주제는 TWTT 소개, 스내사 아침 러닝 챌린지, 기수별 회고, 실제 개최 모임이다. 지역 키워드는 실제 활동 지역만 사용한다. ‘강남’ 날씨를 쓰고 있다는 이유로 모든 모임이 강남에서 열린다고 소개하지 않는다.

구현 시 공개 본문을 서버에서 HTML로 제공하고, 페이지별 제목·설명·대표 주소·공유 이미지를 작성한다. 메뉴·기수·모임 연결에는 실제 링크를 사용한다. [Google JavaScript SEO 안내](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics).

공개 페이지 sitemap을 제출하고 Search Console에서 대표 주소와 색인 상태를 확인한다. 개인 기록·인증 원본·운영 화면은 검색 대상에서 제외하고 별도 접근 제어를 유지한다. 운영 중인 기존 인증 서비스의 검색 설정을 일괄 해제하지 않는다.

월별 지표는 검색 노출·클릭, 공개 소개에서 참가 신청으로 이동한 비율, 모임 신청 완료 수다. 게시한 회고 수와 실제 가입 전환을 함께 보고, 의미 없는 검색어 반복 페이지를 대량 생성하지 않는다.
