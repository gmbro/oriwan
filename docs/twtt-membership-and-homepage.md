# TWTT 홈페이지·구독·공동 목표 업데이트

2026-09-13 사용자 수정안을 반영한다. 이 문서의 공동 목표가 이전 growth-plan의 2,027km + 주간 루틴 제안을 대체한다. 홈페이지·구독은 상품 기획 단계이며 아직 실제 결제/예약 상품으로 판매하지 않는다.

## 공동 목표 — 구현

메인 인증률 배너 안에 4개 목표를 표시한다. 처음에는 1,000km / ??? / ??? / ???. 공식 승인 러닝 거리 합계가 1,000km에 도달하면 첫 번째에 체크하고 두 번째 2,027km를 공개한다. 이어 5,000km, 10,000km 순서다. 거리 목표는 매 단계 추가 거리이거나 초기화되는 거리가 아니라 시즌 전체 누적값이다.

준비 기간·검수 대기·반려·회복 인증 환산 거리는 제외하고 기존 회원별 운동일 중복 제거 규칙을 따른다. 집계 수정으로 기준 아래로 내려가면 체크와 다음 단계 공개 상태도 다시 계산한다. 표시용 반올림 전에 달성을 판정한다. 잠금은 화면의 순차 공개 연출이며 숫자를 보안 정보로 숨기는 기능은 아니다.

## 구독 — 혜택 확정안과 운영 제안

상품명 제안: **TWTT 함께 관리 멤버십**. 다음 세 가지를 핵심 혜택으로 한다.

| 혜택 | 운영 제안 |
| --- | --- |
| 광고 일주일 무료 노출 | 유효한 구독 기간마다 승인된 소재 1건, 연속 7일. 기본 위치는 4기 대시보드. 새 홈페이지 광고까지 포함하는지는 별도 상품으로 정한다. |
| 운영자 업로드 무료 대행 | 구독자 자신의 운동 캡처를 운영자가 등록. 추가 건당 요금 없이 기본 하루 1건, 누락일 소급 요청 가능. OCR·날짜·시간 확인과 승인 기준은 동일. |
| 교정운동 월 1회 무료 | 구독 기간당 1회 예약권. 제안 범위는 20~30분 온라인 운동 자세 피드백. 대면·의료 진료와 구분하고 실제 담당자·시간·장소를 확정한 뒤 판매. |

‘광고 7일’은 가입 시 1회인지 매월인지 미정이므로 **매 구독 기간 1회**를 추천한다. 단, 20명만 가입해도 월 140 광고일이 필요하므로 한 자리 독점 노출을 약속하면 안 된다. 광고 로테이션 내 7일 노출로 안내하고 동시 슬롯·표시 빈도·소재 검수·대기일을 먼저 정한다. 일반 월 10,000원 광고와 상품/청구를 분리한다. 과장·불법 광고는 무료 혜택이어도 게시하지 않는다.

결제는 1차 **계좌이체 + 운영자 입금 확인으로 1개월 활성화**를 추천한다. 자동결제로 오해되지 않게 ‘월 이용권, 수동 연장’이라고 표시한다. 가격은 확정하지 않았다. 산정은 `(월 업로드 처리시간 × 인건비 + 교정 세션 원가 + 광고 운영비 + 결제/고객지원비) ÷ 예상 이용회원 + 여유분`으로 검토한다. 특히 교정운동 제공 가능 횟수에 맞춰 초기 가입 정원을 제한한다.

가입 흐름: 카카오 로그인 → 혜택·기간·요금·환불 확인 → 신청번호 발급 → 계좌이체 → 운영자 실제 입금 확인 → 시작일·종료일 저장 → 내 멤버십에서 잔여 광고권/교정운동권 표시. 신청자의 입금 완료 버튼만으로 활성화하지 않는다.

무료 회원은 계속 직접 업로드할 수 있다. 유료는 업로드 대행을 받고, 결제 여부와 관계없이 사진의 운동 날짜와 오전 8시 이전 증거를 같은 기준으로 검수한다. 구독은 승인 자체를 구매하는 상품이 아니다. 해지·만료돼도 기존 인증 기록은 남는다.

어드민 구성: 입금대기/활성/만료 회원 → 대행 업로드 큐 → 광고 소재·예약 달력 → 교정운동 예약·완료 → 환불·혜택 사용 이력. 광고권·예약권은 한 번만 사용되도록 서버 트랜잭션과 고유키로 중복 처리 방지. 원본 운동 캡처는 전용 업로드함에서만 받으며 제3자 공유를 피한다.

기간은 결제일부터 다음 달 같은 날짜 직전(월말 보정), 사용하지 않은 혜택은 기본 이월 없음, 운영자 사유 취소는 재예약/대체 제공을 제안한다. 실제 환불·예약 취소·노쇼·혜택 사용 후 해지 기준은 결제 전에 약관으로 확정한다. 자동 갱신은 운영량이 안정된 뒤 PG 계약·동의·서버 검증·중복청구 방지·해지 기능을 갖춰 도입한다. [토스페이먼츠 자동결제 안내](https://docs.tosspayments.com/guides/v2/billing).

## TWTT 공개 홈페이지 — 권장 구조

별도 도메인을 새로 살 필요는 없다. 기존 TWTT 도메인의 `/`를 공개 홈페이지로 만들고 `/4th/dashboard`는 현재 서비스로 유지하면 된다. Google이 이해할 수 있는 공개 설명 페이지가 핵심이며 홈페이지를 만드는 것만으로 상위 노출이 보장되지는 않는다. [Google SEO 기본 가이드](https://developers.google.com/search/docs/fundamentals/seo-starter-guide).

| 메뉴 | 공개 내용 |
| --- | --- |
| 홈 | TWTT 소개, 현재 진행 중인 스내사 4기, 공동 목표, 가입 안내, 후원 광고 |
| 스내사 4기 | 일정·규칙·참가 방법·공동 누적거리·공개 동의한 도전자 프로필 |
| 지난 시즌 | 1·2·3기 소개와 결과·회고. 검증된 자료가 있는 기수만 공개. 현재 3기 읽기 전용 자료 재사용 가능. |
| 커뮤니티 모임 | 러닝·교정운동·번개 모임 목록, 장소·시간·정원·주최자, 신청 버튼 |
| 멤버십 | 무료/유료 비교, 광고 혜택, 업로드 대행, 교정운동, 비용·해지 안내 |
| 파트너/광고 | 광고 신청·소재 규격·위치·노출 기간·검수 기준 |

도전자 노출은 선택 동의를 받는다. 공개 닉네임·소개·대표 사진 정도로 시작하고 실제 운동 원본, 상세 이동 경로, 카카오 식별자, 연락처는 검색 페이지에 넣지 않는다. 모임 연락·참석자 정보는 로그인 후 필요한 범위만 공개한다. 유료 광고 링크에는 `rel="sponsored noopener"`를 적용하고 광고 표시를 한다.

SEO 구현 항목: 페이지별 고유 제목/설명, canonical, 실제 본문과 일치하는 구조화 데이터, 공개 페이지 sitemap, 모바일 속도, 이미지 최적화, Search Console 소유권 확인. 회원 개인화 화면의 noindex와 접근 권한은 유지한다. 검색 노출 지표와 가입/모임 신청 전환을 월별로 확인한다.

권장 순서: 공개 홈·4기 소개 → 3기 아카이브 → 멤버십 수동 이용권 → 모임 목록/신청 → 검증 자료 확보 후 1·2기 → 자동결제. 기존 대시보드의 회원 전체를 동의 없이 검색용 홈페이지로 복사하지 않는다.
