# TWTT 공개 후원·광고 참여 기획

2026-09-13 · 후원 선택지와 송금 연결은 기획 단계다. 현재 내 정보에는 안내 화면만 있으며 아래 결제·계좌 복사 기능은 아직 연결하지 않았다.

## 누구나 들어오는 후원 화면

공통 대시보드 하단에 ‘TWTT 응원하기’를 두고 공개 주소 `/support`로 연결한다. 로그인 없이 열 수 있고, 내 정보의 기록 옆 ‘운영자 후원’에서도 같은 화면으로 이동한다. 비회원·무료 회원·구독자 모두 이용할 수 있다. 구독과 일회성 후원을 분리한다.

화면 제목: **함께 이어가는 TWTT**

본문(요청 문구 그대로):

> 후원은 자유롭게 선택할 수 있어요. 후원 여부는 인증 승인과 서비스 이용에 영향을 주지 않아요. 보내주신 응원은 서버 운영과 인증 관리, 커뮤니티 운영에 보탬이 됩니다.

| 선택지 | 누르면 표시할 내용 | 완료 처리 |
| --- | --- | --- |
| 마음으로 응원하기 | 따뜻한 하트 모션과 ‘응원해주셔서 고마워요!’ | 비용·로그인·개인정보 입력 없이 로컬 피드백만 제공. 근거 없는 후원자 수는 표시하지 않음 |
| 커피 쿠폰 선물하기 | ‘카카오 선물하기에서 커피 한 잔으로 응원해주세요’와 외부 이동 안내 | 실제 운영자 수신자 연결 URL로 이동. 외부 결제 결과를 확인할 수 없으므로 자동으로 선물 완료 처리하지 않음 |
| 인프라 비용 지원하기 · 10,000원 | ‘1회 자율 후원 · 자동결제 아님’, 신한은행, **110-489-915994**, 예금주, 계좌번호 복사 버튼 | 계좌 복사는 송금이 아님. 입금 완료 버튼만으로 실제 입금 확인 처리하지 않음 |

입금 선택 화면에는 **신한 110-489-915994 / 10,000원**을 명확하게 보여준다. 예금주는 아직 제공되지 않았으므로 임의 이름을 넣지 않는다. 실제 송금 기능을 출시하기 전에 예금주와 운영자용 카카오 선물하기 수신 URL이 필요하다. 일반 카카오 선물하기 홈만 연결하면 받는 사람이 지정되지 않으므로 운영자에게 전달되는 링크인지 확인 후 사용한다.

공개 후원자 명단이나 금액 순위는 만들지 않는 것을 권장한다. 후원 내역 확인이 필요한 경우에만 별도 문의로 처리한다. 영수증·세액공제 가능 여부를 확인 없이 약속하지 않는다. 후원 오류·취소 문의 채널도 화면 하단에 제공한다.

## 누구나 광고 문의

배너 위의 ‘광고 문의는 개인 연락부탁드립니다.’ 문구는 삭제한다. 광고를 보는 사람의 콘텐츠 영역에 반복 안내하지 않는다.

공통 대시보드 하단에 ‘광고 등록·문의’를 별도 배치하고 공개 `/partners` 페이지로 연결한다. 비회원도 위치·규격·기간·월 10,000원 상품 설명을 보고 문의할 수 있도록 한다. 문의는 누구나 가능하지만 게시에는 운영자 소재 검수와 입금 확인이 필요하다. 구독자의 무료 노출 혜택은 기존 정책과 별도로 안내한다.

후원은 대가 없는 자율 응원, 광고는 노출 서비스를 구매하는 상품으로 화면과 처리 이력을 분리한다.

## 개발·확인 순서

1. 공개 후원 화면과 마음으로 응원하기, 계좌 복사 UI 구현.
2. 예금주·운영자 카카오 선물 수신 링크 확인 후 외부 이동 연결.
3. 로그인 없이 모바일에서 세 선택지 접근 가능 여부, 정확한 계좌 복사, 외부 이동 실패·복귀 확인.
4. 공개 광고 문의 화면 연결. 게시·결제 확인은 운영자만 처리.

로그인해야 볼 수 있는 다른 회원의 기록은 후원 화면과 분리한다. 후원 여부가 기록 열람 권한이나 공식 승인 기준을 바꾸지 않는다.
