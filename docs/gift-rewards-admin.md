# 오늘의 인증 보상 운영

초기 구성: 포춘쿠키 형식의 긍정적인 운세·하루 시작 응원 20개(각 4.5%, 합계 90%). 스내사 크루 재능기부 1회권 3.34%, 보난자 커피 쿠폰 3.33%, 교정운동 무료 1회권 3.33%로 상품 합계 10%다. 문구 원본은 `lib/gift-rewards.ts`의 FORTUNE_MESSAGES에 있다. 기존 명언 목록과 독립적으로 관리한다.

어드민 → 응원상자 탭에서 문구·상품·확률을 변경하고 저장한다. 전체 확률 합계가 100%일 때만 저장할 수 있다. 0%는 추첨 중지이며 항목 추가·제거도 가능하다. 변경된 설정은 이후 추첨에 적용한다. 과거 당첨 문구는 수정하거나 다시 추첨하지 않는다. 어드민에는 최근 상품 당첨 최대 100건의 회원·날짜·당첨 ID도 표시한다.

추첨은 인증 완료 여부와 회원 소유권을 서버에서 검증한 뒤 암호학적 난수 0~9,999로 수행한다. 시즌·회원·운동일 고유 제약으로 동시에 여러 요청을 보내도 최종 기록은 한 건이며, 재요청은 저장된 결과를 반환한다. 각 추첨의 확률이 90/10인 것이며 회원 열 명마다 상품 한 개를 보장하는 방식은 아니다.

설정은 기존 비공개 저장소의 운영 계정별 JSON에 저장하고, 관리자 API만 읽기·변경할 수 있다. 설정이 아직 없는 계정은 초기 구성으로 동작하며 서버 장애·잘못된 설정은 추첨 실패로 처리한다.

시각 연출: 5초 흔들림 → 1.5초 뚜껑 열림 → 폭죽과 보상. 서버가 늦으면 결과를 꾸며내지 않고 흔들림 상태로 기다린다. 동작 줄이기 설정에서는 긴 연출을 생략한다. 상단 ‘오늘 인증 보상’ 문구를 제거하고 결과 카드에 ‘오늘의 인증 보상’을 표시한다.

상품은 당첨권 기록이며 실제 커피 바코드나 예약 확정서가 아니다. 운영자는 당첨 ID 확인 후 쿠폰 전달·이용 일정 조율을 수동으로 진행한다. 쿠폰 자동 발송, 재고 차감, 사용 완료 추적은 이번 구현에 포함되지 않는다. 제공할 수 없는 상품은 어드민에서 0%로 바꾸고 나머지 확률을 조정한다. 명칭이 같은 상품을 다시 등록해도 기존 당첨 기록은 보존된다.

로컬 `/preview/gift-box`는 초기 확률을 사용하는 예시이며 실제 수령·설정 저장을 하지 않는다.
