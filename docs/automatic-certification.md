# Immediate certification

Member submissions with an owned image draft and valid date, distance and duration are certified on save. OCR values can be corrected; workout-start time and manual review are not approval gates. Administrator uploads certify complete records; unresolved member/date/metrics require completion before saving. Existing records are not bulk-converted. Official season totals still begin September 23.

Gift-box results must not be overwritten by the opening animation finishing. Only a changed initial snapshot synchronizes into the child state. Claims remain unique per member and date.

Header actions use compact transparent text buttons. Member auth uses persistent, renewable Supabase cookies; administrator verification uses a signed one-year cookie renewed on authenticated session reads. Explicit logout clears the current device session.
