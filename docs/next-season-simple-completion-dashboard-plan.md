# 스내사 다음 시즌 기획 — 100번의 아침

> 기존 대시보드의 구조와 캐릭터는 재사용하고, 공통 화면은 `오늘 인증 완료 여부`에만 집중하는 경량 리디자인안 0.1

## 1. 한 문장 정의

**공통 화면에서는 서로의 “오늘 해냈다”만 보고, 거리와 운동시간은 캐릭터를 눌렀을 때만 확인하는 100일 아침 루틴 대시보드.**

게임 재화, 상점, 지도 이동, 경쟁 순위를 새로 만들지 않는다. 기존 대시보드의 헤더, 참가자 캐릭터 그리드, 개인 팝업을 재사용하면서 색, 문구, 상태 표현과 정보 우선순위만 바꾼다.

## 2. 이번 기획의 목표

### 목표 행동

- 참가자가 매일 오전 8시 전에 3km를 완료한다.
- 속도나 초과 거리보다 정해진 아침 루틴을 반복한다.
- 하루를 놓쳐도 다음 날 다시 시작한다.
- 다른 참가자의 성과 수치보다 함께 참여하고 있다는 감각을 얻는다.

### 성공 경험

1. 공통 대시보드에서 오늘 아침의 공동 분위기를 확인한다.
2. 자신의 3km 인증이 반영되면 캐릭터에 불이 켜진다.
3. 자신의 캐릭터를 눌러 오늘 기록과 쌓인 아침을 확인한다.
4. 한 주와 10일 단위의 작은 변화를 발견한다.
5. 결석 후에도 손실 없이 다시 돌아온다.

### 이번 범위에서 하지 않을 것

- 거리·속도·완료 시각 순위
- 완료자 우선 정렬
- 공개 스트릭 경쟁
- 코인, 상점, 아이템 거래
- 3D 마을, 지도 이동, 건설 시스템
- 초과 거리에 비례한 공개 보상
- 미완료자에게 빨간색, X, 경고 문구 표시

기존 스내사빌리지·코인 기획은 삭제하지 않고 별도의 후속 아이디어로 보관한다.

## 3. 핵심 인증 규칙

### 기본 판정

```text
한국시간 오전 07:59:59까지 끝난 유효 활동의 당일 합산 거리 >= 3.00km
→ 오늘 인증 완료
```

- 여러 기록은 같은 날짜 안에서 합산한다.
- 판정 기준은 업로드 시각이 아니라 실제 활동 시각이다.
- 인증 자료 업로드는 당일 23:59:59까지 허용한다.
- 운영자는 마감 후에도 실제 활동 날짜에 기록을 추가할 수 있다.
- 오전 8시 이후 운동 기록도 개인 기록에는 보존하지만 `오늘 오전 인증 완료`에는 포함하지 않는다.
- 3km를 넘겨도 인증 상태와 공통 화면의 보상은 동일하다.

### 안전 가드레일

- 마감 직전에는 `서두르세요`, `몇 분 남았어요` 같은 압박 문구를 사용하지 않는다.
- 개인의 평소 3km 소요시간을 알 수 있다면 안전하게 출발할 수 있는 마지막 시각을 미리 안내한다.
- 충분한 시간이 남지 않았다면 정시 인증을 재촉하지 않고 안전하게 운동 기록을 남기도록 안내한다.
- 달리는 도중 사진 제출이나 화면 조작을 유도하지 않는다.
- 준비운동과 정리운동은 권장하되 인증 통과 조건이나 경쟁 점수로 만들지 않는다.

## 4. 공통 대시보드

### 유지하는 기존 구조

- 시즌 제목과 오늘 날짜가 있는 헤더
- 오늘의 현황을 보여주는 히어로 영역
- 참가자 캐릭터 카드 그리드
- 캐릭터 클릭 시 열리는 개인 팝업
- 기존 실시간 갱신 구조
- 기존의 가벼운 벡터 캐릭터 자산

### 상단에 보여줄 정보

```text
100번의 아침
DAY 24 / 100

오늘 아침, 20명 중 14명이 불을 켰어요.
```

공동 진행률은 숫자를 경쟁시키는 용도가 아니라 배경 분위기를 바꾸는 데만 사용한다.

- 0~29%: 고요한 새벽
- 30~59%: 동이 트는 하늘
- 60~79%: 따뜻한 아침빛
- 80% 이상: 밝은 아침 마을

100%만 특별 보상의 조건으로 삼지 않는다. 한 사람의 누락이 공동 실패가 되는 구조를 피하기 위해 60~80% 구간에서도 충분한 시각적 변화를 제공한다.

### 참가자 카드

모든 참가자는 매일 같은 위치에 둔다. 완료 순서나 거리로 재정렬하지 않는다.

| 상태 | 공개 표현 |
|---|---|
| 오전 8시 전 3km 완료 | 캐릭터 뒤의 따뜻한 해무리, 작은 체크, `완료` |
| 아직 완료되지 않음 | 평온한 기본 캐릭터, 상태 문구 없음 |

- 이름은 기존처럼 가운데 글자를 `*`로 가린다.
- 완료 캐릭터만 1회 짧게 기지개를 켜거나 빛이 퍼진다.
- 미완료 캐릭터를 흐리게 만들거나 별도 구역에 모으지 않는다.
- `실패`, `거리 부족`, `시간 초과`, 미완료 사유는 공개하지 않는다.

여기서 “완료된 것만 보인다”는 **완료한 참가자만 목록에 남긴다**는 뜻이 아니라, **모든 참가자를 같은 자리에 두되 완료 여부 외의 성과 정보는 보이지 않는다**는 뜻으로 설계한다. 이 방식이 공동체 소속감을 유지하면서도 미완료자를 낙인찍지 않는다.

### 공통 화면에서 제거할 것

- 캐릭터 카드의 거리·운동시간 배지
- 누적 거리와 누적 진행률 막대
- 인증률·거리·운동시간 정렬 버튼
- 리더보드와 순위
- 리커버리 추이
- 공개 100일 상세 리포트
- 참가자 소개글
- 인증 사진, 앱명, GPS 경로
- 개인 최고 기록과 스트릭

이전 시즌의 기록 화면은 동결하고 관리자만 접근한다. 새 시즌은 화면 코드를 복사하지 않고 기존 컴포넌트를 그대로 재사용하되, 시즌 설정·색상 토큰·표시 필드만 교체해 새 시즌 데이터만 읽는다.

## 5. 캐릭터 클릭 개인 창

캐릭터를 눌렀을 때만 그 참가자의 기록을 불러온다.

### 다른 참가자도 볼 수 있는 최소 정보

```text
신*희
오늘 인증 완료

3.24km
운동시간 31분
오전 8시 전 완료

100일 중 17번째 아침
현재 연속 인증 5일
시즌 인증 거리 54.8km
```

- 오늘 오전 8시 전 유효 거리 합계
- 운동 소요시간
- 인증 완료 여부
- 시즌 중 인증한 아침 수
- 현재 연속 인증 일수
- 시즌 인증 누적 거리
- 날짜별 완료/빈칸으로 구성한 100일 모자이크

`운동시간`은 31분 같은 **소요시간**을 뜻한다. 정확한 시작·종료 시각은 생활 패턴을 드러낼 수 있으므로 공개 팝업에는 기본적으로 노출하지 않는다.

### 본인과 관리자에게만 보이는 정보

- 정확한 시작·종료 시각
- 여러 활동의 개별 거리와 시간
- 오전 8시 이후 기록
- 인증 사진과 원본 앱명
- 운영자 수정 이력
- GPS 경로와 위치정보

GPS 경로와 사진의 위치 메타데이터는 공개하지 않는다.

### 팝업의 정보 순서

1. 오늘 `완료 / 아직`
2. 오늘 유효 거리와 운동시간
3. `100일 중 몇 번째 아침`이라는 누적 참여 횟수
4. 현재 연속 인증 일수
5. 시즌 인증 누적 거리
6. 이번 주에 인증한 아침 수
7. 10일 챕터 진행
8. 100일 모자이크
9. 최고 스트릭은 접힌 보조 정보

스트릭보다 누적 참여와 복귀 기록을 먼저 보여준다. 하루 누락이 시즌 전체의 실패처럼 느껴지지 않게 하기 위해서다.

## 6. 동기부여 설계

새로운 경제 시스템 대신 `오늘 → 이번 주 → 10일 챕터 → 100일`의 네 겹 피드백을 사용한다.

### 6.1 오늘: 즉시 보이는 변화

인증이 반영되면 다음 순서로 1~2초만 연출한다.

1. 캐릭터가 기지개를 켠다.
2. 캐릭터 뒤에 작은 아침빛이 켜진다.
3. 오늘 칸에 잎사귀 도장이 찍힌다.

완료 문구는 경쟁이 아니라 행동 사실을 말한다.

- `오늘의 아침을 열었어요.`
- `100일 중 17번째 아침이에요.`
- `오늘도 3km면 충분해요.`
- `어제 쉬고 오늘 다시 돌아왔어요.`

### 6.2 이번 주: 연속보다 리듬

개인 창에는 이번 주의 일곱 칸을 보여준다.

```text
이번 주의 아침
월 ●  화 ●  수 ○  목 ●  금 ○  토 ○  일 ○
```

- 3회: `첫걸음 잎`
- 5회: `리듬 잎`
- 7회: `가득한 아침 잎`

잎사귀는 무료 도감에만 쌓이며 구매, 거래, 순위 점수가 없다. 3회와 5회에도 의미 있는 기록을 남겨 7회를 놓쳤다고 한 주 전체가 실패가 되지 않게 한다.

### 6.3 10일: 계절 챕터

100일을 10일씩 10개 챕터로 나눈다. 각 챕터에서 6일·8일·10일 인증 시 동·은·금 인장을 남긴다. 이전 인장은 다음 챕터에서도 보존된다.

1. 첫빛
2. 익숙한 길
3. 단풍 리듬
4. 깊어진 아침
5. 첫서리
6. 겨울 입구
7. 긴 밤의 약속
8. 하얀 숨
9. 다시 길어지는 빛
10. 백 번째 아침

챕터가 바뀔 때 레이아웃은 그대로 두고 하늘색, 작은 식물, 창문의 불빛 같은 배경 요소만 바꾼다.

### 6.4 100일: 나만의 기록물

시즌 마지막에는 순위표 대신 개인 기록 포스터를 만든다.

- 100칸 아침 모자이크
- 인증한 아침 수
- 오전 인증 누적 거리
- 가장 긴 스트릭
- 누락 후 다시 돌아온 횟수
- 모은 잎사귀와 챕터 인장

문구 예시:

> 100일 동안 78번의 아침을 만들고, 7번 다시 돌아왔어요.

완벽한 100회뿐 아니라 반복과 복귀도 의미 있게 남긴다.

## 7. 결석과 복귀 경험

### 공개 화면

- 빈 날은 빨간 X가 아니라 아무 표시 없는 기본 상태로 둔다.
- 결석 횟수, 스트릭 중단, 복귀 여부를 다른 참가자에게 공개하지 않는다.
- 미완료자에게 단체 책임을 지우는 문구를 사용하지 않는다.

### 개인 화면

하루 누락:

> 어제 칸은 비어 있지만 지금까지의 기록은 그대로예요. 오늘 한 번이면 다시 이어집니다.

이틀 누락:

> 놓친 거리를 갚을 필요는 없어요. 오늘은 편안한 3km로 돌아오세요.

복귀 인증 완료:

> 쉬었다가 다시 나온 아침도 루틴의 일부예요.

복귀 시 별도 코인이나 더 큰 보상을 주지 않는다. 대신 `다시 돌아온 잎`을 무료 도감에 기록한다.

## 8. 전날과 아침의 개인 루틴 도구

공통 대시보드에는 보이지 않고 로그인한 본인에게만 제공한다.

### 전날 약속

```text
내일 몇 시에 나갈까요?
[06:20] [06:40] [07:00] [직접 입력]

비가 오면
[실내 3km] [시간을 다시 정할게요]
```

선택 후에는 실행 문장으로 바꾼다.

> 내일 06:40에 알람이 울리면 준비해 둔 신발을 신고 나갑니다.

### 아침 안내

여유가 있을 때:

> 좋은 아침이에요. 오늘도 3km만, 서두르지 않게.

시간이 충분하지 않을 때:

> 8시까지 서두르지 않아도 괜찮아요. 안전하게 움직이고 오늘의 기록을 남겨주세요.

오전 8시가 지난 뒤:

> 아침 목표는 지났지만 오늘의 움직임까지 사라진 것은 아니에요. 내일의 출발 시각을 미리 정해볼까요?

### 러닝 전후

- 시작 전: `5분 준비 걷기`
- 완료 후: `5분 천천히 걷기`
- 건너뛰어도 인증이나 누적 기록을 깎지 않는다.
- 수행 시 경제적 보상 대신 무료 `돌봄 잎사귀`만 남긴다.

## 9. 톤앤매너

### 콘셉트

**고요한 새벽이 참가자들의 인증으로 천천히 밝아지는 100일의 아침.**

### 시각 방향

- 기존 어두운 배경과 강한 라임 포인트를 부드러운 새벽색으로 전환한다.
- 기본 배경: 짙은 새벽 남색 → 안개 낀 라벤더
- 완료 포인트: 살구빛 → 따뜻한 코랄빛
- 카드: 부드러운 크림색과 낮은 대비의 반투명 레이어
- 성공 상태: 번쩍이는 효과보다 천천히 퍼지는 해무리
- 실패 상태: 별도 경고색 없음
- 기존 캐릭터 형태는 유지하고 표정, 빛, 작은 동작만 추가한다.

### 카피 원칙

사용할 표현:

- `속도보다 반복을 기록합니다.`
- `오늘 한 번이면 다시 이어집니다.`
- `더 달리지 않아도 오늘 목표는 충분합니다.`
- `몸 상태에 맞는 선택도 루틴의 일부입니다.`

피할 표현:

- `실패했습니다.`
- `모두 기다리고 있어요.`
- `스트릭이 곧 사라집니다.`
- `조금만 더 뛰면 다른 사람을 이깁니다.`

## 10. 정보와 API 경계

CSS로 수치만 숨기면 브라우저에 이미 전달된 데이터가 노출될 수 있다. 새 시즌에는 요약 데이터와 상세 데이터를 분리한다.

### 공통 대시보드 응답

```text
participant_id
masked_name
character_id
today_completed
```

### 캐릭터 클릭 시 상세 응답

```text
today_valid_distance
today_duration
season_completed_days
season_valid_distance
current_streak
best_streak
weekly_completed_days
chapter_completed_days
completion_calendar
```

### 본인·관리자 전용 응답

```text
exact_start_at
exact_end_at
individual_activities
late_activities
proof_image
source_app
admin_audit_log
```

공통 화면의 초기 응답에는 거리, 시간, 사진, 위치정보를 싣지 않는다. 캐릭터를 눌렀을 때 필요한 최소 상세만 별도로 조회한다.

## 12. 로컬 구현 순서

### 1단계 — 이전 시즌 동결 확인

- 이전 시즌 데이터 쓰기 차단
- 이전 시즌 화면 관리자 전용 확인
- 새 시즌 데이터셋과 날짜 범위 분리

### 2단계 — 공통 화면 단순화

- 기존 대시보드 컴포넌트를 재사용하고 시즌 설정만 분리
- 공개 수치를 완료 여부로 축소
- 카드 순서 고정
- 순위, 정렬, 거리, 시간, 소개글, 리커버리, 리포트 제거

### 3단계 — 개인 창 분리

- 캐릭터 클릭 시 상세 데이터 지연 조회
- 공개 상세와 본인·관리자 상세 권한 분리
- 100일 모자이크와 완료 문구 적용

### 4단계 — 톤앤매너

- 새벽·아침 색상 토큰 적용
- 완료 해무리와 1회 애니메이션
- 후속으로 10일 챕터별 배경 변화 적용

### 5단계 — 후속 동기부여

- 무료 잎사귀 도감
- 주간·10일 리듬 피드백
- 결석 후 복귀 문구
- 전날 약속과 안전한 아침 안내

모든 단계는 로컬에서만 진행하며, 별도 요청 전에는 푸시·배포·프로덕션 데이터 변경을 하지 않는다.

### 첫 구현 범위와 후속 범위

첫 구현에는 다음만 포함한다.

- 시즌 설정과 새 색상 토큰
- 공통 화면의 완료 여부와 완료 인원
- 고정된 참가자 카드 순서
- 캐릭터 클릭 시 상세 기록 지연 조회
- 완료 해무리
- 계산형 주간 3·5·7 스탬프와 챕터 6·8·10 인장
- 결석 후 복귀 문구

다음은 첫 구현 검증 후 추가한다.

- 전날 약속 도구
- 개인 소요시간 기반 안전 출발 시각 안내
- 챕터별 배경 10종
- 캐릭터 추가 동작
- 시즌 종료 포스터 생성

잎사귀와 인장은 별도 인벤토리나 아이템 데이터베이스를 만들지 않고 기록에서 계산해 개인 창에 그린다.

## 13. 성공 지표

순위나 총거리 대신 루틴의 형성과 복귀를 측정한다.

- 오전 8시 전 3km 일일 완료율
- 첫 7일 이후 재방문율
- 주간 3회·5회·7회 달성 분포
- 결석 다음 날 복귀율
- 3일 이상 공백 후 복귀율
- 전날 약속을 만든 사람의 다음 날 시작률
- 시즌 중도 이탈률
- 인증 직전 과도한 마감 집중 여부

## 14. 결정이 필요한 네 가지

### 1. 공개 개인 창의 시간 범위

권장안은 다른 참가자에게 `운동 소요시간`만 보여주고, 정확한 시작·종료 시각은 본인과 관리자에게만 보여주는 것이다.

### 2. 오전 8시 판정

이 문서는 사용자의 현재 표현에 맞춰 `오전 8시 전에 당일 합산 3km를 완료`로 가정했다. 판정은 실제 활동 종료 시각을 사용하고 업로드는 당일 늦게 허용한다.

### 3. 오전 8시 이후 거리의 누적 범위

권장안은 공개 개인 창의 `시즌 인증 거리`에는 오전 8시 전 인증에 사용된 거리만 합산하고, 오전 8시 이후 활동은 본인·관리자 전용 `전체 활동 기록`에만 남기는 것이다.

### 4. 인정 가능한 활동

건강한 루틴을 우선하면 야외 러닝뿐 아니라 런·워크와 트레드밀 3km도 동일하게 인정하는 편이 좋다. 걷기만 허용할지는 운영 정책으로 확정해야 한다.

## 15. 최종 추천

새 시즌의 핵심은 게임을 더 만드는 것이 아니라 **정보를 덜 보여주고, 완료의 감정적 피드백을 더 잘 만드는 것**이다.

- 공통 화면: 함께 켜진 오늘의 아침빛
- 캐릭터 창: 거리와 운동시간, 나의 100일 기록
- 개인 루틴: 전날 약속, 안전한 출발, 복귀 안내
- 장기 동기: 무료 잎사귀, 10일 계절 변화, 시즌 기록 포스터

이 구성은 기존 대시보드의 골격을 거의 그대로 활용하면서도 다음 시즌을 별개의 경험으로 느끼게 하고, 무거운 게임 시스템 없이도 매일 돌아올 이유를 만든다.
