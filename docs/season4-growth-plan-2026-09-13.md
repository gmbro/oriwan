# 스내사 4기: 검색 노출·구독·공동 목표 기획

2026-09-13 제안. 아래 신규 상품·목표·SEO 화면은 기획이며 현재 배포 기능과 구분한다. 공식 기간은 기존 코드 기준 2026-09-23~12-31, 100일이다.

## 1. 구글에서 발견되는 공개 입구

현재 `/4th`와 `/4th/dashboard`는 `noindex`이므로 검색 노출을 기대하기 어렵다. 회원 이름·사진·개인 통계를 검색 대상으로 바꾸는 대신 공개 소개 페이지 `/snasa`를 만든다. 검색용 제목은 **스내사 | 스스로 내던지는 사람들, 아침 러닝 챌린지**를 제안한다.

공개 페이지 순서: 크루 소개 → 4기 100일과 2,027km 목표 → 참여 방법 → 오전 8시 이전 운동 인증 규칙 → 무료·구독 차이 → 자주 묻는 질문 → 참가하기. 로그인 없이 읽을 수 있는 HTML 본문과 실제 활동 사진(공개 동의 확보)을 제공한다. 검색어를 반복해서 채우기보다 초보자가 궁금해하는 시간·장소·비용·온라인 참여 여부를 명확하게 답한다.

실행 순서:

1. 공개 소개와 `/challenge/4th`의 고유 title·description·canonical·OG 이미지·이미지 설명을 작성한다. 실제 제공하는 활동과 지역만 명시한다.
2. 대표 도메인 HTTPS를 하나로 통일한다. sitemap에는 공개 페이지만 넣는다. 개인 화면·어드민·인증 원본·테스트 페이지는 제외하고 인증 및 권한 검사도 유지한다.
3. Search Console 소유권 확인 → sitemap 제출 → URL 검사 → 색인 요청을 진행한다. 도메인 소유권 접근이 필요한 작업은 운영 계정에서 한다.
4. 주 1회 공개 주간 회고: 공동 누적 거리, 참여 방법, 공개 동의된 경험을 독자적인 글로 남긴다. 인스타·기존 커뮤니티 프로필에서 공개 소개 페이지로 연결한다.
5. 4주 단위로 브랜드/비브랜드 검색 노출·클릭·참가 버튼 클릭·가입 전환을 비교한다. 분석 이벤트에 이름·인증 이미지·개인 운동 기록을 보내지 않는다.

`noindex`는 검색 제외 지시이며 robots.txt로 크롤링까지 막으면 그 지시를 읽지 못할 수 있다. 검색 제외는 접근 제어가 아니다. 검색 순위나 색인을 보장하는 방식은 없다. 근거: [Google 검색 제외 안내](https://developers.google.com/search/docs/crawling-indexing/block-indexing), [SEO 기본 가이드](https://developers.google.com/search/docs/fundamentals/seo-starter-guide).

## 2. 구독자는 운영자 관리, 무료는 직접 업로드

추천 상품은 **기록 관리 구독**이다. 유료 혜택은 제출 대행·누락 알림·검수 지원이며 인증 기준은 모두 동일하게 적용한다. 월 10,000원 광고 상품과 회원 구독 가격은 별개다. 회원 가격은 아직 정하지 않았다.

| 항목 | 무료 직접 등록 | 유료 기록 관리 |
| --- | --- | --- |
| 제출 | 본인이 로그인 후 사진 업로드·거리 확인 | 본인 제출 또는 동의한 운영자가 대신 등록 |
| OCR | 운동 날짜·시각·거리·소요시간 추출 | 동일 기준 |
| 검수 | 현재 정책대로 운영자 최종 확인 | 운영자 관리 목록·누락 확인·우선 처리 |
| 반려 | 이유·수정 경로 제공 | 동일 + 보완 안내 |
| 구독 종료 | 계속 무료 업로드 가능 | 대행 기능만 종료, 기존 승인 기록 유지 |

사용자 요청을 엄격히 ‘구독자만 운영자 승인’으로 적용하려면 무료 제출을 자동 승인 또는 개인 기록 전용으로 바꿔야 한다. 이는 기존 **모든 최종 승인은 운영자** 정책과 충돌한다. 권장 1차안은 위 표처럼 무료의 기본 검수를 유지하고 관리 노동에 과금하는 것이다. 대안은 무료 기록을 `self_reported`로 따로 표시하고 공식 공동 목표에는 검증 기록만 반영하는 방식이지만 무료 참가자의 기여가 제한되므로 권장하지 않는다. 이 정책 선택을 확정하기 전 결제 여부로 승인 권한을 차단하지 않는다.

공통 승인 규칙: 업로드 시각과 무관하게 사진의 운동일·운동시각을 판독하고 한국시간 오전 8시 이전인지 확인한다. 시간·날짜 누락, 중복 사진, 불명확한 OCR은 보완 요청한다. 결제 자체로 승인되지 않는다. 현재 구현은 OCR 보조 후 운영자 최종 승인이다.

운영 화면: 구독 관리(시작/종료/상태/입금) → 관리 대상 회원 → 미제출·검수대기·보완요청 → 사진·OCR 증거 확인 → 승인/반려. 대행 업로드에는 제출자와 회원 소유자를 별도로 기록한다. 회원 동의 없이 메신저 전체 대화를 수집하지 않는다.

초기 결제는 계좌이체로 시작한다. 신청 → 주문번호·상품·기간·금액 생성 → 운영자 실제 입금 확인 → 서버에서 구독 활성화. 이용자의 ‘입금 완료’ 버튼으로 활성화하지 않는다. 환불·만료·중복 입금·부분 입금 이력을 보존한다. 월별 수동 연장은 자동결제라고 표시하지 않는다.

추후 PG: 결제 승인 응답의 주문번호·금액·상태를 서버 검증하고 웹훅 서명·멱등성을 확인한다. 반복 결제는 계약과 이용자 동의를 갖추고 빌링키를 서버에만 저장한다. 해지 시 다음 청구를 중단하고 기존 유효기간까지 혜택을 유지한다. [토스페이먼츠 자동결제 안내](https://docs.tosspayments.com/guides/v2/billing).

제안 DB: `subscription_plans`, `payment_orders`, `subscriptions`, `subscription_events`, `record_submissions`. 결제 상태와 기록 승인 상태를 별도로 관리하고 서버에서 회원·기간·권한을 확인한다. 가격·부가세 포함 여부·제공 시간·환불·개인정보 보유기간은 판매 전 확정한다.

## 3. 첫 번째 목표: 함께 2,027km, 2027년으로

**“100일 동안 우리의 발걸음을 모아 2,027km를 완성합니다.”** 개인 할당량이 아닌 크루 공동 목표다. 100일 기준 크루 하루 평균 20.27km이며, 10명이면 1인 주평균 약 14.2km, 20명이면 약 7.1km다. 이는 일정 참고치이며 매일 달릴 의무가 아니다.

집계는 공식 기간 내 운동일의 승인된 실제 러닝 거리만 합산한다. 준비 러닝·승인대기·반려·중복·삭제 기록은 제외한다. 회복활동을 인증용으로 환산한 가상 거리는 넣지 않는다. 기존 인증 점수·환산거리와 별도의 `approvedRunningDistanceKm` 집계가 필요하다. 반려 전환·수정 시 재계산하며 합산 후 표시 단계에서만 반올림한다.

시즌 종료 후 7일간 소급 제출·검수를 받는 마감안을 제안한다. 운동일이 12월 31일 이내여야 하며, 제출 마감은 2027-01-07 23:59 KST, 결과 확정은 01-08로 공지한다. 현재 업로드 시각과 무관한 승인 정책에 새로운 시즌 정산 마감 규칙을 추가하는 것이므로 사전 공지가 필요하다.

대시보드: `현재 000.0 / 2,027km`, 달성률, 남은 거리, 주간 기여, 마지막 집계 시각. 507·1,014·1,520·2,027km에서 25·50·75·100% 축하 연출을 제공한다. 목표를 넘으면 실제 누적값을 계속 표시한다. 개인정보 없는 공동 수치만 공개 소개에 공유한다.

## 4. 두 번째 목표: 함께 꾸준히, 주 3회 루틴

추천: **“참가자 80%가 14주 중 10주 이상, 주 3일 활동 인증하기.”** 첫 목표가 총량이라면 두 번째는 소수의 장거리 러너에게만 의존하지 않는 참여 지속성이다.

9월 23일부터 수~화 기준 7일씩 14개 주를 계산하고 마지막 12월 30~31일은 거리에는 포함하되 주간 달성 계산에서는 제외한다. 같은 날 여러 기록은 활동일 1일이다. 러닝 또는 사전에 합의한 회복운동의 승인 기록을 인정하되 단순 휴식 체크·댓글은 활동 인증으로 계산하지 않는다. 회복운동은 공동 러닝 거리와 분리한다.

시작일의 참가 동의 완료 인원을 N명으로 확정해 목표 인원은 `ceil(N × 0.8)`로 고정한다. 중도 가입자는 개인 진행률을 보여주되 공식 분모를 임의로 바꾸지 않는다. 중도 탈퇴로 목표를 쉽게 만들지 않으며 불가피한 운영 변경은 변경 이력과 사유를 공개한다. 최종 기간·분모·회복 인정 기준은 시작 전 공지한다.

화면은 개인 `이번 주 2/3일 · 성공한 주 6/10주`, 크루 `루틴 완성 8/목표 16명`처럼 보여준다. 미달성자 실명 순위나 공개 낙인은 피하고 개인 알림과 응원으로 복귀를 돕는다.

대안 ‘응원 2,027개’는 분위기 조성에 좋지만 반복 댓글을 유도할 수 있어 보조 이벤트로 둔다. ‘모두 매일 100일’은 휴식·일정 변화에 취약하다. 4기의 두 축으로는 **공동 거리 + 꾸준한 참여**를 추천한다.

## 구현 순서와 완료 기준

1. 공개 소개·SEO: 로그인 없이 본문 확인, canonical·sitemap·색인 지시 검사, Search Console 확인.
2. 목표 집계: 실제 승인 거리와 활동일 분리. 중복·반려·수정·기간 경계 테스트 후 집계 카드를 공개.
3. 수동 구독: 가격·혜택·환불 규칙 확정 후 입금 확인과 기간 만료 기능. 무료/구독 모두 승인 기준 일치 확인.
4. 운영량이 늘면 PG·청구 자동화. 만료·중복 웹훅·환불·해지 테스트 후 실결제 전환.
