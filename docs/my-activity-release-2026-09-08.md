## 적용 내용

- 상단 본인 이름 → 내 활동. PC 요약은 우측 420px, 상세는 중앙 팝업, 모바일은 하단 시트. 틀·닫기부터 즉시 표시하고 내용은 분할 로드한다.
- 사진 선택·미리보기·저장·기본 사진 복귀, 표시 이름 변경. 계정/참가자 ID로 소유권을 검증하며 이름으로 기록을 재연결하지 않는다. 이름 변경은 동시 수정 검사와 실패 시 조건부 보상 처리를 적용한다.
- 공개 멤버창은 본인도 읽기 전용. 공개 댓글의 작성·답글·삭제·반응도 내 활동의 댓글 관리로 이동한다. 기존 목표/운세/응원/문의 진입점은 같은 내 활동 팝업 안에서 열린다. 운영자 권한은 유지한다.
- 인증샷: 사진 선택 → 전송률 → OCR → 날짜·거리·분/초 확인·보완 → 검수 제출. 닫기·메뉴 이동 후에도 업로드 초안과 프로필 입력을 유지한다. 계정 변경/로그아웃 시 편집 트리를 폐기한다.
- 개인 제출은 서버가 `needs_review`로 저장한다. 사용자 요청의 participant ID·user ID·승인 상태는 신뢰하지 않는다. 공식 인증률/공식 그래프는 승인 후 반영하고, 인식된 거리·시간은 확인 단계와 제출 후 캘린더에 먼저 표시한다.
- 기존 승인 기록을 덮어쓰지 않는다. 날짜별 DB 유일키로 중복을 방지하고 같은 초안 재제출은 기존 기록을 반환한다. 미래 날짜·시즌 밖·비정상 수치·타인/만료 초안은 거절한다.
- 캡처본은 `member-run-uploads` private Storage에 보관한다. 이미지 포맷·실제 디코딩·픽셀/전송 용량을 검사하고 EXIF/GPS를 제거한다. 원문·OCR 원문은 공개 대시보드로 보내지 않는다. 사진 열람 API는 본인 또는 관리자만 허용한다. 관리자 인증 상세에 사진 보기 링크를 추가했다.
- 하루 8장 제한은 Storage의 원자적 INSERT로 서버 인스턴스 간 공유한다. 같은 날짜/사진의 결과는 재사용한다. 실패·한도 초과·중복 처리 상태를 구분한다. 고가 모델 자동 재시도는 없다.
- 거리/시간/인증일, 최근 7일/30일/전체 SVG 누적 그래프와 인증 캘린더. 검수 대기와 시즌 전 기록은 공식 집계와 구분한다. 차트 패키지는 추가하지 않았다.
- 배너 우측 하단 날씨 정보 삭제. 강남구 예보 기반 배경/강수 연출은 유지하고 MET Norway·CC BY 4.0 출처만 페이지 하단에 표시한다. 기존 64초 회색길 경로, 2.4초 발걸음, 제한 모션·팝업 중 일시정지를 유지한다.

## OCR 선택 근거와 비용

공식 가격표상 `gemini-2.5-flash-lite`가 더 저렴하지만 운영 API 실호출이 `model_not_found`로 거절됐다. 이 후보는 검증 단계에서 중단하고 도메인에 연결하지 않았다. 현재 연결에서 동작 확인된 다음 저비용 이미지 모델 `gemini-3.1-flash-lite`를 단독 사용한다. 기존 기본 모델 이름 자체는 동일하며, 비싼 `gemini-3.5-flash` 자동 추가 호출을 없앤 것이 주요 비용 개선이다. SDK 자동 재시도도 1회 호출로 제한했다. 낮은 확신의 관리자 OCR도 자동 승인 대신 확인 중으로 보낸다.

- [Google 공식 가격](https://ai.google.dev/gemini-api/docs/pricing): 3.1 Flash-Lite Standard 입력 $0.25 / 출력 $1.50 (100만 토큰당). 이미지 입력 지원. 대기 시간이 큰 Batch/Flex는 즉각적인 확인 UX와 맞지 않아 사용하지 않았다.
- 서버 시험 이미지: 2026-09-08 / 5.20km / 32:10 모두 정확. 입력 1,662·출력 167·thinking 0 토큰. 동일 토큰 가정의 API 비용 약 $0.000666/장, 1,000장 약 $0.666. 실제 이미지/출력 길이, 요금제, Storage/트래픽 비용에 따라 달라진다.
- 비밀키 전체를 로컬로 내려받는 방식은 보안 검사에서 차단되어 사용하지 않았다. 검증 스크립트는 배포 환경 안의 기존 키를 사용하며 키·요청 원문을 출력하지 않는다.

- TypeScript·수정 파일 ESLint·로컬 및 Vercel 운영 빌드 통과.
- 배포 빌드 게이트: 실제 Gemini 이미지 호출, private Storage 쓰기/읽기, anonymous 읽기/서명 URL 생성/쓰기 차단, 기록 스키마 확인 모두 통과. 매번 생성한 검증용 JSON 객체는 제거했다. 기존 회원/인증 기록은 시험 목적으로 수정하지 않았다.

- 최종 운영 도메인: 대시보드 200, 개인 기록 GET/개인 OCR POST 401 및 private/no-store, `/preview/my-activity` 404, `/me`는 `/4th/dashboard#my-activity`로 307 이동. 강남구 예보 API 200·정상 예보 응답. 실제 운영 320px 화면 가로 넘침·날씨 배지·콘솔 오류 없음.
