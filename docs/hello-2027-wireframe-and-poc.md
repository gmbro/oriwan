# TWTT 4th Hello 2027 — 최종 와이어프레임 및 로컬 PoC 명세

## 화면 목적

- 이전 시즌 운영 화면과 데이터는 건드리지 않고 새 시즌의 모바일 우선 화면을 검증한다.
- 참가자 로그인 없이 운영자가 이름, 인증 기록, 캐릭터 번호를 등록하는 구조를 전제로 한다.
- 공개 화면에는 오늘의 공동 인증률과 주간·월간 요약을 보여준다.
- 개인 카드에는 풀네임과 시즌 현재까지의 인증률만 표시한다.
- 개인 거리와 운동시간은 캐릭터를 눌렀을 때만 보여준다.

로컬 PoC 경로: `/poc/hello-2027`

## 시간대별 장면

서울 시간을 공통 기준으로 삼고 배경 이미지의 밝기·채도·색 오버레이를 서서히 전환한다. 별도의 6개 대형 이미지를 동시에 불러오지 않는다.

| 서울 시간 | 장면 |
|---|---|
| 22:00–04:59 | 밤 |
| 05:00–06:59 | 해뜰녘 |
| 07:00–09:59 | 아침 |
| 10:00–16:59 | 낮 |
| 17:00–18:59 | 해질녘 |
| 19:00–21:59 | 저녁 |

- 1분마다 현재 단계를 확인하고 탭 복귀·포커스 시 즉시 다시 계산한다.
- 단계가 바뀌면 필터와 색 오버레이를 90초 동안 서서히 전환한다.
- 운영체제의 저감 모션 설정에서는 전환 애니메이션을 생략한다.
- 시간대 효과는 장식으로 처리하고 인증 정보의 가독성에는 영향을 주지 않는다.

## 캐릭터 원칙

- 상단 풍경에는 캐릭터를 넣지 않고 시간대가 변하는 강변 배경만 보여준다.
- 참가자 카드와 상세창에는 얼굴만 보이며, 운영자 등록 이미지가 없을 때 캐릭터 얼굴을 사용한다.
- 참가자 20명은 고정된 20개 색상 조합과 5개 액세서리를 사용해 서로 다르게 표현한다.
- 완료자에게만 오른쪽 위 `인증완료` 배지를 표시하며, 누적 인증률로 재정렬하지 않는다.
- 기본은 가나다 이름순이며 이용자가 `인증완료순`으로만 바꿔볼 수 있다.

## UI 원칙

- Pretendard Variable을 PoC 안에 자체 포함해 기기와 관계없이 같은 글꼴로 보여준다.
- 본문 폭은 최대 1200px로 제한하고 흰 화면, 중립 회색, 단일 블루 포인트 색만 사용한다.
- 작은 테두리 박스를 반복하지 않고 넉넉한 여백과 하나의 3분할 요약 패널로 정보 위계를 만든다.
- 그림자와 애니메이션은 최소화하고 제목·본문·보조 정보의 크기 차이로 가독성을 확보한다.

## 로컬 운영자 관리

로컬 관리 경로: `/poc/hello-2027/manage`

- 기존 `/admin`, Supabase, 시즌 데이터와 완전히 분리한다.
- 광고는 기본 인증 현황 슬라이드와 별도로 최대 10개까지 등록·수정·순서 변경·삭제할 수 있다.
- 첫 슬라이드는 고정 인증률 화면이며 이후 광고는 전체 배너 이미지로 표시하고 5초마다 자동 전환한다. 포인터·키보드·터치 조작 중에는 멈추고 저감 모션 설정에서는 자동 전환하지 않는다.
- 오늘의 응원글은 기본 56개이며 최대 56개까지 등록·수정·순서 변경·삭제할 수 있다. 공개 화면에서는 8초마다 순환한다.
- 광고 이미지와 참가자 얼굴 이미지는 IndexedDB에 Blob으로 저장하고 메타데이터 제거·리사이즈 후 사용한다.
- 참가자 ID 기준으로 얼굴 이미지와 소개 제목·자기소개를 관리한다. 이미지가 없거나 읽기 실패 시 캐릭터 얼굴로 돌아가고, 소개를 저장하지 않으면 기본 소개를 사용한다.
- 같은 브라우저의 다른 탭에는 BroadcastChannel로 변경 사실을 알려 즉시 다시 읽는다.
- 브라우저 데이터를 지우면 사라지는 개발용 PoC이며 실제 운영 단계에서는 인증된 어드민과 영구 저장소로 교체한다.

## 댓글

- 댓글과 답글을 쓰기 전 `실명쓰기` 또는 `랜덤`을 고른다. 랜덤은 등록 순간 포근한 닉네임을 배정한다.
- 로그인 없는 PoC이므로 실명 입력은 인증된 신원이 아니라 사용자가 직접 적는 표시명임을 화면에 알린다.
- 댓글과 답글은 작성자와 오른쪽 상단 날짜·시간, 본문, 이모지 반응 순서로 표시한다.
- 대댓글은 모바일 가독성을 위해 한 단계만 허용한다.
- 답글은 기본적으로 접고 `답글 n개 보기`와 `답글 접기`로 전환한다.
- 본문은 일반 텍스트로만 렌더링하며 댓글과 답글 모두 150자로 제한한다.
- PoC에서는 동일 브라우저의 IndexedDB에 저장한다. 실제 공개 전에는 속도 제한, 신고·숨김, 운영자 삭제가 필요하다.

## 실제 어드민 연결 시 교체 경계

현재 화면은 정적 fixture만 사용하며 API, 기존 시즌 데이터, Supabase에 연결되지 않는다. 실제 구현 단계에서는 데이터 공급부만 다음 값으로 교체한다.

- 시즌: 이름, 시작일, 종료일, 기준 날짜, 경과일, D-day, 공동 목표
- 참가자: 고정 ID, 풀네임, 고유 캐릭터 번호, 시즌 누적 인증률
- 인증: 활동 날짜, 거리, 운동시간, 인증 완료 여부
- 공동 집계: 오늘·주간·월간 인증률

운영자 화면은 위 값을 일괄 등록·수정하고, 공개 화면은 승인된 스냅샷을 읽기만 하는 단방향 구조로 연결한다.

## PoC 안전장치

- 개발 환경에서만 열리고 프로덕션 빌드에서는 404 처리한다.
- 검색 엔진 색인을 차단한다.
- 임의 이름과 가상 기록만 포함한다.
- 기존 `/dashboard`, 어드민, 공개 API 코드를 수정하지 않는다.
- 로그인과 서버 저장은 포함하지 않는다. 광고·얼굴·응원글·게시판 데이터는 현재 기기의 IndexedDB에만 저장한다.
- 게시판은 React 일반 텍스트 렌더링, 길이·개수 제한, 이미지 시그니처 검사와 메타데이터 제거를 적용한다. 실제 공개 전에는 인증·권한·속도 제한·신고·숨김·운영자 삭제를 서버에서 추가한다.
