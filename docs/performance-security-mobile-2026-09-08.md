# 2026-09-08 성능·보안·모바일 개선

## 적용 범위

- 공통 대시보드 갱신 시 멤버 조회가 끝나야 댓글·콘텐츠 갱신을 시작하던 순서를 해제했다.
- 댓글의 로그인 사용자 확인과 DB 조회를 병렬로 진행하되, 수정·삭제 권한은 확인된 사용자로 계산한다.
- 반복 갱신 요청은 진행 중인 요청 하나와 대기 요청 하나로 합친다. 화면을 떠나면 조회를 중단하고, 일시적인 오류에는 기존 표시 내용을 유지한다.
- 공개 콘텐츠·배너·프로필 이미지 요청에서 불필요한 인증 갱신 미들웨어를 제외했다. 개인·운영자 API의 권한 검사는 유지한다.
- 서버의 대시보드 갱신 알림은 WebSocket 구독을 기다리지 않고 제한 시간 2초의 HTTP 전송을 사용한다.
- 모바일 입력 글자 크기 16px, 안전 영역 여백, 작은 화면 카드 정렬, 캘린더 버튼의 44px 터치 영역을 적용했다. 모바일 공통 카드의 배경 블러를 제거했다.
- 빈 오류 영역, 잘못된 연결 상태 문구와 운영자 화면의 띄어쓰기 등을 정리했다.

## 보안 개선

- Content-Length가 없거나 부정확한 요청에도 실제 스트림을 읽으면서 JSON·파일 요청 용량을 제한한다.
- 이미지 디코딩 전에 JPG·PNG·WebP 파일 시그니처와 선언된 형식이 일치하는지 검사한다.
- 요청 제한용 메모리 맵 크기를 제한한다. 이는 서버 인스턴스별 방어이며 분산 요청 제한을 대체하지 않는다.
- 오류 응답은 private, no-store로 처리한다.
- 설치된 Next.js 16.3.3은 [공식 2026년 8월 보안 릴리스](https://nextjs.org/blog/august-2026-security-release)의 수정 버전이다. 전체 의존성 취약점 검사나 침투 테스트를 수행했다는 의미는 아니다.

## 기존 인증샷 비공개 열람

운영 DB의 저장소 설정과 경로 집계를 읽기 전용으로 확인했다.

- `photos`, `snasa-gallery`, `member-run-uploads`는 이미 비공개 저장소였다.
- 기존 인증 이미지가 연결된 기록은 1,854건(3기 1,850건, 4기 4건)이며, `photos/run-records/`의 저장 객체 1,883개는 그대로 보존했다. 원본 이동·삭제·백필은 하지 않았다.
- 기존 `photos`와 `snasa-gallery`의 브라우저 직접 접근 차단 정책을 유지했다. `member-run-uploads`에도 anon/authenticated 역할의 직접 접근을 차단하는 명시적 restrictive 정책을 추가했다. 운영 SQL 실행 결과는 성공이었다.
- 마이그레이션: `docs/migrations/2026-09-08-private-run-image-access.sql`.
- 인증샷은 `/api/me/records/image/[id]`에서 운영자 인증 또는 해당 시즌의 승인된 본인 계정 연결을 확인한 후 제공한다. 저장 경로를 임의로 입력할 수 없으며 비공개·저장 금지 응답으로 제공한다.
- 기존 시즌에서 본인 계정 연결이 없는 기록은 운영자만 열람한다. 이름만 같은 계정을 임의로 연결하지 않는다.
- 내 활동의 날짜별 기록과 운영자 기록 상세에 인증샷 열람 링크를 연결했다. 공통 멤버 화면에는 인증샷 링크를 노출하지 않는다.
- 이미 다운로드된 외부 사본은 회수할 수 없다. 이번 변경은 앱·저장소의 앞으로의 접근을 제한한다.

## 배포 및 확인 범위

사용자가 후속 요청에서 **테스트 후 배포**로 변경했다. 검증 생략 설정의 배포 시도는 안전 검토에서 중단됐으며 운영에 반영되지 않았다.

- 자동 테스트 115개 통과: 본인·운영자 인증샷 접근, 타인·미연결·비활성 계정 거부, 파일 시그니처, 청크 요청 용량 제한 등 포함.
- TypeScript 검사 통과. 첫 배포 후보에서 발견된 참가자 정렬 값의 타입 오류를 수정했다.
- 운영 빌드 환경의 비공개 파일 읽기·쓰기, 익명 읽기·서명 URL 발급·쓰기 차단 및 기록 스키마 검사 통과. 합성 임시 파일만 사용하고 정리했으며 실제 회원 기록은 수정하지 않았다.
- 실제 저비용 OCR 모델에 합성 이미지의 날짜·5.20km·32:10 인식 검사 통과.
- 320px·390px 브라우저에서 내 정보 메뉴와 프로필 정렬 확인. 가로 넘침 없음, 입력 글자 16px 확인.
- 1440px 데스크톱 정렬, 파일 선택 → 예시 기록 확인 → 탭 전환 시 초안 유지 → 예시 제출 완료, 개인 기능 진입·뒤로가기 확인. 실제 회원 기록은 수정하지 않았다.
- 보호된 Vercel 배포 후보에서 공개 콘텐츠 요청이 미리보기 세션을 잃는 문제를 발견해 same-origin 쿠키 전달을 유지했다. 공개 콘텐츠 API는 개인 인증·개인 데이터 조회 없이 명언 50개와 광고 2개를 반환한다.
- 부하 테스트·전체 의존성 감사·실제 카카오 신규 가입은 수행하지 않았다. 실제 응답 시간이 특정 수치로 단축됐다고 보장하지 않는다.

## 추가 주석 반영

- 명언 전환 6초 → 18초, 배너 자동 전환 7초 → 14초.

- 프로필 사진 선택·표시 이름·저장을 한 카드로 통합하고 중복 설명을 제거했다. 사진 저장 후 이름 저장이 실패하면 일부 저장 상태를 안내한다.

- 인증샷 화면의 코드도 미리 준비해 첫 클릭의 로딩 전환을 줄였다.
