## 원인과 수정

- 첨부된 hydration 오류는 미리보기 하단의 이전 서버 문구와 새 브라우저 문구가 달랐다는 내용이다. 실행 중인 개발 서버와 별도로 생성한 운영 번들에 서로 다른 문구가 남아 있었다. 개발 출력은 `.next-local`, 운영 출력은 `.next`로 분리했다. 미리보기 안내는 서버에서 렌더링한 노드를 전달해 두 환경에서 별도로 정의하지 않는다. 경고 숨김이나 hydration 경고 억제는 사용하지 않았다.
- 러너가 고정된 독립 좌표에서 제자리 달리기를 해 잔디·분홍색 차선에 놓여 있었다. 원본 배경의 회색 차선 안쪽에 발 접지점 경로를 정의하고, 공통 배경 좌표계에서 움직이게 했다.
- 발걸음 주기: 1.2초 → 2.4초. 경로 한 바퀴는 64초이며, 멀어질수록 인물이 작아지고 굽은 길 끝에서 사라진다. 가까운 쪽 재등장은 페이드 처리한다. 5명의 시작 시점이 서로 다르다.
- 이미지 파일과 총 191,218바이트 에셋 용량은 그대로다. CSS transform/opacity만 사용하며 매 프레임 React 렌더링을 추가하지 않았다. 정지·모션 줄이기에서도 발 위치가 회색길에 남는다.
