# 2026-09-08 대시보드 추가 주석 14개 반영

## 변경 사항

- TODAY·날짜·서울 현재 시각을 좁은 화면에서도 한 줄로 표시한다. 분 단위 갱신은 유지한다.
- 멤버 정렬 컨트롤은 폭 148px, 배경 높이 32px로 축소했다. 버튼의 터치 영역은 44px 높이를 유지한다.
- 멤버 수를 `멤버` 제목 아래로 이동했다.
- 댓글 작성 폼 상단의 이름 선택 영역을 제거하고, 등록 버튼 옆에 `익명으로 남기기` 체크박스를 배치했다. 기본값은 본인 이름이며 체크할 때만 익명이다. 답글에도 같은 방식을 적용하고 전송 중에는 변경을 막는다. 서버의 계정 연결·소유권 검사는 유지한다.
- 내 정보의 메뉴 이름은 유지하고, 하위 화면에서 반복되던 프로필·인증샷·기록 제목만 제거했다.
- 배너에는 D-day만 표시한다. 기준 날짜는 접근성 설명에 유지한다.
- 공통 멤버창의 `인증 기록`, `N일째 인증 중`과 캘린더의 `4기 공식 인증 기준` 문구를 제거했다.
- 멤버창 상단에 총 인증일·누적 달린 거리·누적 시간을 3열로 배치하고 캘린더 하단의 중복 총 인증일 영역을 숨겼다.
- 공통 요약의 주간·월간 인증률을 총 누적거리·총 누적 시간으로 교체했다.

## 집계 기준

공통 요약은 기존 시즌 지표와 동일하게 2026-09-23~12-31 기간의 승인 기록을 오늘까지 집계한다. 활성 공개 멤버만 포함하며 멤버·날짜별 중복을 제거한다. 거리·시간의 비정상 값은 제외하고, 시간은 초를 모두 더한 뒤 분으로 반올림한다. 9월 8일 현재 공식 시즌 시작 전이므로 0km·0분이 정상이다.

멤버별 상세창의 거리·시간은 기존처럼 준비 기간과 확인 중인 유효 기록도 포함한다. 이번 UI 요청에서 해당 기준은 변경하지 않았다. 실제 회원 데이터 변경이나 재집계 백필은 없다.
