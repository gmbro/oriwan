# 2026-09-14 멤버 승인·콘텐츠

신규 카카오 로그인은 승인 대기 계정과 비공개 참가 초안으로 저장한다. 기존 승인 멤버는 유지한다. 대기·철회 계정은 재로그인으로 승인되지 않는다. 어드민 멤버 화면의 ‘카카오 멤버 승인’에서 승인하기를 누르면 멤버로 공개된다.

댓글은 승인된 로그인 멤버에게만 표시한다. 비로그인·승인 대기는 제목·건수·로그인 안내 없이 섹션을 생략하고, API 조회·작성·수정·삭제·반응도 차단한다. 공개 스냅샷에는 댓글을 포함하지 않는다. 개인 상세 기록도 승인 멤버만 접근한다.

멤버 기록 캘린더 아래 운영자가 입력한 자기소개 제목·본문을 표시한다. 본문이 없으면 빈 영역은 만들지 않는다.

멤버 목록 아래 ‘러너를 위한 교정 운동 콘텐츠’를 추가했다. 사용자 제공 영상 https://www.youtube.com/shorts/LXYYMxVWAZk 를 미리보기로 제공하고 클릭 시에만 YouTube 플레이어를 불러온다. 인터뷰 영역은 표시하지 않는다.

참관객의 이름·거리·시간 공개, IP당 응원, 광고 보상, archi-landing.cloud 이전은 별도 기획에 반영했다. 해당 기능과 도메인 변경은 이 배포에 포함하지 않는다.

150개 테스트 및 TypeScript 검사 통과. 실제 계정 승인이나 테스트 댓글 작성은 하지 않았다.
