## 응원 선물 관리자 기획

현재 사용 경로: **관리자 → 응원글 → 응원글 추가 → 문구(120자 이하) → 공개 → 저장**. 활성 문구 최대 56개가 랜덤 지급 대상이다. 표시 순서는 대시보드 문구 순환 순서이며, 선물 당첨 확률을 조정하지 않는다. 수정해도 이미 지급된 문구는 수령 기록에 보존된다.

확장 화면은 **선물 관리 / 지급 내역**으로 나눈다. 관리자 응원글 화면에 현재 등록 방법과 확장 범위를 안내한다. 쿠폰·실물 지급은 현재 출시된 기능이 아니며 다음 설계대로 추가한다.

| 등록 항목 | 내용 |
| --- | --- |
| 기본 정보 | 선물명, 유형(응원 문구/디지털 쿠폰/실물/교정운동 이용권), 이미지, 설명, 후원자 |
| 운영 기간 | 한국시간 시작일·종료일, 수령/사용 만료일 |
| 지급 조건 | 시즌, 인증일 범위, 준비 인증 포함 여부, 1인 지급 한도 |
| 재고 | 총수량·예약수량·지급완료수량, 품절 시 응원 문구로 대체 |
| 추첨 | 가중치 및 실제 표시 확률, 재고·기간을 반영한 미리보기 |
| 지급 방식 | 쿠폰 코드 개별 등록, 운영자 전달, 현장 수령. 배송정보는 당첨 후 별도 수집 |
| 게시 상태 | 초안 → 검토 → 공개 → 중지/만료. 지급 이력 있는 항목은 삭제 대신 중지 |

저장 구조: `gift_catalog`(정의), `gift_inventory`(코드/재고), 기존 `daily_gift_claims`(선물ID와 지급 당시 내용 스냅샷), `gift_fulfillments`(전달/수령 상태), 관리자 감사 이력. 공개 화면이나 목록 API에는 쿠폰 코드·배송정보를 보내지 않는다.

추첨은 인증 확인·중복 수령 확인·재고 차감·결과 저장을 **하나의 DB 트랜잭션**에서 수행한다. 동일 시즌·참가자·인증일 고유키와 재고 행 잠금으로 동시 요청을 막는다. 응답 유실 시 같은 결과를 반환한다. 재고 마지막 1개를 두 명이 동시에 요청하는 테스트가 필수다. 과거 승인도 선물을 놓치지 않도록 미개봉 인증일 목록과 시즌 종료 후 7일 수령 유예를 제안한다.

실물·쿠폰 공개 전에는 당첨 조건, 수량, 수령 기한, 품절 대체, 배송정보 수집·파기를 고지하고 현재 약관의 '현금이나 상품으로 교환되지 않는 메시지' 조항을 개정한다.

## 월 10,000원 광고 운영 제안

초기에는 **계좌이체 + 운영자 입금 확인**을 권한다. 광고 수가 적을 때 구현·정산 부담이 적다. 광고 등록 화면은 현재 이미지·문구·공개 여부만 관리하며 결제 확인·자동 만료는 아직 없다.

1. 광고 신청을 비공개로 접수한다. 서버에서 월 이용료 10,000원을 고정한다.
2. 광고주·입금자명·청구월·결제방법·입금확인자·확인시각을 저장한다.
3. 운영자가 실제 계좌 내역을 확인하고 승인한다. 신청자의 '입금 완료' 클릭만으로 공개하지 않는다.
4. 노출 시작·종료 시간을 저장하고, 서버의 공개 조회에서 기간과 입금 확인 상태를 모두 검사한다. 만료 스케줄 실패에도 광고가 연장되지 않도록 한다.
5. 연장은 다음 월 청구 건으로 기록한다. 환불·취소 이력과 금액을 보존한다.

'한 달'은 매월 동일 일자까지인지 30일인지 먼저 정한다. 권장안은 시작일~다음 달 같은 날 직전이며 월말은 말일로 보정한다. 10,000원의 부가세 포함 여부, 광고 중도 종료·검수 반려 환불 기준, 사업자 증빙 발급 방식은 청구 전 확정할 항목이다. 계좌번호나 세금 정책은 임의로 만들지 않았다.

확장 시 토스페이먼츠 일반 결제부터 붙이고 반복 청구가 필요할 때 빌링으로 전환한다. 빌링키는 서버에만 보관하고 청구 스케줄·주문 고유키·실패 재시도·해지 처리를 구현해야 한다. 결제창 성공 리다이렉트만으로 게시하지 않고 서버 승인 결과의 주문·금액·상태를 검증한다.

근거: [토스페이먼츠 자동결제 가이드](https://docs.tosspayments.com/guides/v2/billing), [연동·테스트 및 계약 안내](https://docs.tosspayments.com/guides/v2/billing/integration). 2026-09-13 확인. PG 계약·수수료·실결제 연동은 이번 작업에서 실행하지 않았다.
