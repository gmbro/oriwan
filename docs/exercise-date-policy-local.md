# 운동 날짜가 다른 인증샷 처리 — 로컬 검토안

실제 운동일 기준으로 기록을 귀속한다. 9월 13일 운동을 14일에 업로드할 수 있지만 선택 날짜는 13일이어야 한다. 오늘의 인증으로 이월하지 않는다. 늦은 제출은 운영자 검토 후 원래 날짜에 반영하고 같은 날짜의 기존 기록이 있으면 수정 요청으로 처리한다.

권장 서버 정책(이번 로컬 UI 변경에서 새로 강제하지 않음):
- OCR에서 절대 운동 날짜를 확인했고 선택 날짜와 다르면 제출 전에 날짜 수정 안내. 사용자가 선택한 날짜와 OCR 근거를 함께 운영자에게 남긴다.
- Today/Yesterday는 업로드 날짜만으로 계산하지 않는다. 예전 캡처이거나 기기 시간대가 달라질 수 있다. 절대 날짜가 나오는 활동 상세 캡처를 요구하거나 운영자가 확인한다.
- 시작 시각과 소요 시간을 분리한다. 사진의 Today · 23:29가 시작 시각으로 확인된다면 오전 8시 이전 인증에 해당하지 않는다. 일반 운동 기록 보관과 공식 아침 인증을 구분하는 후속 정책이 필요하다.
- 사진 저장은 기록 제출이 아니다. 제출 영수증/승인 대기 상태를 확인해야 접수 완료다.

현재 서버는 필수 시작 시각·거리 확인 및 운영자 승인, 날짜당 중복 방지를 유지한다. 날짜 불일치 경고는 이미 있지만 선택 날짜만으로 OCR 날짜를 강제 수정하거나 자동 승인하지 않는다. 이번 작업은 요청에 따라 로컬 화면만 구현하며 배포하지 않는다.
