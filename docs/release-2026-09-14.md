# 2026-09-14 화면 정리·후원·검색 준비

- 내 정보 메뉴: 프로필 / 인증 / 기록 / 후원. 개인 기능: 타임머신 / 인증박스 / 오늘 운세 / 교정운동.
- 타임머신 배지는 작은 프로필 좌상단 표시. TODAY 파란 볼드, 로고는 헤더까지 최상단 이동.
- 인증 안내 중 중복 문구 제거, 시작 시각 안내를 파란 볼드로 강조.
- 후원 문구 수정. 커피 링크는 기존 카카오 선물하기 홈이며 사용자가 받을 사람 이경민을 직접 선택해야 함.
- 후원 완료했어요 버튼은 본인의 완료 표시이며 은행·카카오 결제 검증이 아님. 다음 달 같은 한국 시각까지 메뉴와 후원 선택지를 잠금. 월말은 다음 달 말일로 보정. 재요청은 기존 잠금 시각을 연장하지 않음.
- 로그인은 계정별 서버 저장, 비로그인은 HttpOnly 브라우저 쿠키 식별자로 서버 저장. 비회원 쿠키 삭제·다른 브라우저, 비회원에서 새 로그인으로 바꾸는 경우 동일인 판별은 보장하지 않음. 실제 계좌 송금의 금액·횟수는 제어할 수 없음. 1만원 상한은 안내 정책.
- 홈페이지 `/`를 스내사 공개 소개로 변경. 검색용 제목·본문·canonical·공유 메타, robots.txt, sitemap.xml 추가. 개인 기록을 홈페이지에 출력하지 않으며 `/4th`와 `/4th/dashboard`의 noindex 유지.
- Search Console 미등록 확인. Google 로그인·소유권 검증 후 사이트맵 제출·색인 요청 필요. 홈페이지 공개는 Google 검색 결과 반영 보장이 아님.
- 테스트 147개 통과 및 TypeScript 검사. 로컬 Origin의 localhost/127.0.0.1 같은 포트 별칭은 개발 모드에서만 허용하며 운영 출처 검증은 유지.
